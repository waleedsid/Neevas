[Source repository](https://github.com/waleedsid/PreLovedFinds) · [Hosted preview](https://prelovedfinds.netlify.app/)

## What is in the submission?

The published source contains HTML pages for the storefront, product, about, contact and login views, plus CSS, JavaScript and image assets. A login page alone does not provide an authentication service.

The repository does not contain the React frontend, Django/Express backend, database migrations or Stripe/PayPal integration described in the earlier task notes. Those should not be treated as implemented features.

## Inspect it locally

1. Clone or download [PreLovedFinds](https://github.com/waleedsid/PreLovedFinds).
2. Open `PreLovedFinds/index.html` in a browser.
3. Browse the static pages and inspect the assets in `PreLovedFinds/assets/`.

No Node or Django setup is required for these static files. This documentation review checked the repository structure; it did not validate the hosted site's behavior.
